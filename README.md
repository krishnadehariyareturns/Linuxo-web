# Linuxo landing page — close recreation

Plain HTML, CSS and JavaScript. No framework, package manager, commands, or build step.

## Before publishing
Edit `script.js` and replace `YOUR_DISCORD_SERVER_INVITE_URL` and `YOUR_BOT_INVITE_URL` with your actual links.

The page uses cropped artwork and profile portraits from the generated concept image, including the illustrated footer landscape. Keep all image assets alongside `index.html`.

Open `index.html` to preview or upload the entire folder to static hosting.
